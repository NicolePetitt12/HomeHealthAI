# Home Health AI Design Tokens

## Colors
- Primary Red: #E0162B
- Black: #0B0B0C
- White: #FFFFFF
- Secondary Text: #5A5F6A

## Typography
- Title: Inter Semibold 24
- Body: Inter Regular 16
- Button: Inter Semibold 16

## Brand Rules
- Home Health AI is the primary brand
- Inspector Gnome is the helper / guide
- Tone should be calm, clean, and non-alarming

## UI Components
- Header
- Detection badge
- Score display
- Summary text
- CTA button group
- Expandable accordion sections
- Footer disclaimer

## MVP Design Goal
The MVP should feel:
- polished
- modern
- trustworthy
- easy to understand
- presentation-ready
